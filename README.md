# 🧠 NeuralNet 101: Interactive AI & Neural Network Sandbox

> An interactive, beginner-friendly web application designed to help new AI/ML learners to understand neural networks, activation functions, linear transformations, gradient descent, and more!

🚀 **[Launch Live Interactive Sandbox](https://nho646800-wq.github.io/neuralnet_101/)**

---

## 💡 About The Project

**NeuralNet 101** was created as an educational exploration tool accompanying a deep-dive blog post on machine learning fundamentals. Built with a focus on intuitive visualizations, it bridges theoretical AI concepts with practical, interactive models that the user can play around with to see how the concepts they just learned are applied in the real world.

### 🌟 Key Modules & Features
* **1. Glossary & Analogies:** Intuitive mental models for Neurons, Weights (w), and Biases (b).
* **2. Geometry & Boundaries:** Compare linear decision lines against non-linear circular decision spaces using student performance data.
* **3. Activation Functions:** Interactive curves for **Sigmoid**, **ReLU**, **Tanh**, and **Leaky ReLU**.
* **4. Outdoor Walk Playground:** A 4-step pipeline tracing real-time forward propagation ("Should I take a walk outside today?").
* **5. Training Simulator:** Simplified real-time gradient descent simulation showing model accuracy, loss reduction, and boundary convergence across epochs.
* **6. AI Tutor Companion:** Multi-prompt assistant answering core questions on neural mechanics.
* **🌐 Bilingual Support:** Native English & Vietnamese UI toggle to accommodate both Vietnamese and English-speaking AI/ML beginner enthusiasts.
